## 🌟 Overview

**A-One Books** is a modern, elegant online bookstore built with pure HTML, CSS, and JavaScript. It features a stunning public-facing storefront and a fully functional admin dashboard for managing book inventory — all deployed automatically via Vercel.

## ✨ Features

### 📖 Public Website
- **Elegant Hero Section** with smooth animations
- **Dynamic Book Showcase** — books added in the admin dashboard appear instantly on the homepage
- **About Section** with brand story and statistics
- **Features Grid** highlighting the bookstore's value proposition
- **Reader Testimonials** from satisfied customers
- **Newsletter Subscription** form for the readers club
- **Fully Responsive** design for mobile, tablet, and desktop

### 🔐 Admin Dashboard
- **Secure Login Portal** with credential validation
- **Book Management** — add new books with title, price, and cover image
- **Live Image Preview** before uploading
- **Delete Functionality** — remove books from inventory with confirmation
- **Persistent Storage** using browser localStorage
- **Logout Functionality** with session protection
- **Real-time Inventory List** with cover image thumbnails

## 🛠️ Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Modern styling with CSS variables, Grid, Flexbox, and animations
- **JavaScript (Vanilla)** — Dynamic functionality and localStorage integration
- **Vercel** — Automatic deployment and hosting
- **GitHub** — Version control and repository management
