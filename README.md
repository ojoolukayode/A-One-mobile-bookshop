## 🌟 Overview

**A-One** is a modern, elegant e-commerce website built with pure HTML, CSS, and JavaScript. It features a stunning public-facing storefront and a fully functional admin dashboard for managing inventory — all deployed automatically via Vercel.

## ✨ Features

### 🛍️ Public Website
- **Elegant Hero Section** with smooth animations
- **Dynamic Product Showcase** — products added in the admin dashboard appear instantly on the homepage
- **About Section** with brand story and statistics
- **Features Grid** highlighting the brand's value proposition
- **Testimonials** from satisfied customers
- **Newsletter Subscription** form
- **Fully Responsive** design for mobile, tablet, and desktop

### 🔐 Admin Dashboard
- **Secure Login Portal** with credential validation
- **Product Management** — add new inventory with name, price, and image
- **Live Image Preview** before uploading
- **Persistent Storage** using browser localStorage
- **Logout Functionality** with session protection
- **Real-time Inventory List** with image thumbnails

## 🛠️ Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Modern styling with CSS variables, Grid, Flexbox, and animations
- **JavaScript (Vanilla)** — Dynamic functionality and localStorage integration
- **Vercel** — Automatic deployment and hosting
- **GitHub** — Version control and repository management
